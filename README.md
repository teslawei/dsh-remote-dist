# DSH Remote 直连版

纯原生安卓客户端，直连官方远程通道（DeepSeek Harness 远程配对）。

## 下载

最新版：**v2.6.4** — [APK 直链](https://cdn.jsdelivr.net/gh/teslawei/dsh-remote-dist@main/apk/DSH-Remote-Direct-v2.6.4.apk)（全球 CDN，GitHub Releases 见右侧）

## 功能速览

- 会话列表自动刷新、最后回复预览、运行状态点
- 打字机流式输出、会话内切换模型/推理力度
- **权限审批卡片**：电脑端沙箱提权请求实时弹卡，一键批准/拒绝
- 断线自愈、视图回收、关于页检查更新

## 检查更新

App 内顶栏 ⓘ → 检查更新：自动在 GitHub API / 跳转解析 / jsDelivr 之间切换，APK 走 CDN 直链。
